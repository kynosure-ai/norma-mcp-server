# Supplier Security Policy (fixture)

NORMA MCP server local-development fixture demonstrating cross-framework
adjacency. References ISO/IEC 27001:2022 controls A.5.19 / A.5.20.

## Purpose

Define how access by external suppliers to {{COMPANY_NAME}} information is
governed: due-diligence prior to onboarding, contractual security clauses,
ongoing monitoring, and termination procedures.

## Scope

All third-party suppliers, processors, and outsourced ICT service providers
engaged by {{COMPANY_NAME}} in {{JURISDICTION}}.

## Roles

- {{COMPANY_NAME}} Procurement: maintains the supplier register
- Security Lead: signs off on security clauses prior to contract
- Sector context for {{COMPANY_NAME}} ({{SECTOR}}, {{SIZE}}): aligns supplier
  due-diligence depth to risk classification
