# Access Control Policy (fixture)

This is a NORMA MCP server local-development fixture.
It is NOT part of the production corpus and exists only to allow Plan 41-04
smoke tests to verify the corpus loader path without depending on the real
`gs://kynosure-norma-corpus` bucket (which is created in Plan 41-02 / 41-06).

## Purpose

Establish principles and rules for granting, reviewing, and revoking access to
information assets in line with ISO/IEC 27001 Annex A.5.15 and A.5.16.

## Scope

All employees, contractors, and third parties accessing the organization's
information systems.
